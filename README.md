
# agent-board

> The open-source app everyone uses to manage agents at work.

**Author: Farimazhar**

### What does this repository do?

This is a dashboard to manage your AI workforce in one place. Think of it as a control center for your AI employees.

Imagine you have 3 AI employees:
1.  A Research Agent that does research for you
2.  A Code Agent that writes TypeScript code
3.  A Support Agent that replies to customers

This dashboard lets you:

**1. Monitor Agents:**
See in real-time who is working, who is idle, and who is offline.

**2. Assign Tasks:**
Assign new tasks to any agent like "build a website for me" and it will start working.

**3. Track Progress:**
See how many active tasks each agent has on a single, beautiful screen.

### ✨ Features

- **Agent Management** - Create and manage unlimited AI agents
- **Live Status Tracking** - Real-time status (working / idle / offline)
- **Task Management** - Track active tasks for each agent
- **Beautiful UI** - Clean, modern design inspired by Paperclip
- **Fully Typed** - Built with 100% TypeScript for safety and speed

### 🛠 Tech Stack

- **Framework:** Next.js 14 (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS
